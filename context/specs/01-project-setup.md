# Spec 01 — Project setup & deploy shell

## Goal

Scaffold the Next.js app, wire up the design-system foundation, and get an empty page live on a public Vercel URL. This is the H2–4 "done" criteria: repo scaffolded, empty shell deployed.

## Depends on

Nothing (first unit — see `context/specs/00-build-plan.md`).

## Scope

**In scope:**
- `create-next-app` scaffold — App Router, TypeScript, Tailwind CSS, ESLint
- shadcn/ui initialization
- Color tokens from `context/ui-context.md` added to `app/globals.css`'s `@theme` block as CSS custom properties (no raw hex elsewhere) — this project runs Tailwind v4, which is CSS-first config; there is no `tailwind.config.ts`
- Empty page deployed live on Vercel

**Out of scope (do not build in this spec):**
- Any chat UI, components under `components/chat/`, or the message thread
- Supabase project/schema/migrations (Spec 02)
- Any AI provider wiring (`lib/ai/`)
- `.env` values beyond what's needed for a static empty deploy to succeed

## Files to create / modify

- Project scaffold at repo root (`app/`, `public/`, config files) per the folder structure in `architecture.md` — already partially present (Next.js 16 + Tailwind v4 + shadcn/ui already scaffolded and committed/in progress)
- `app/globals.css` — add the 8 color tokens from `ui-context.md` as CSS custom properties + `@theme` entries (no `tailwind.config.ts` — Tailwind v4 is CSS-first)
- `app/layout.tsx`, `app/page.tsx` — minimal, no custom UI yet
- `components/ui/` — shadcn primitives only, as generated by the shadcn CLI (do not hand-edit)
- `.gitignore`, `package.json`, `tsconfig.json` — as generated, reviewed for correctness

## Steps

1. ~~Run `create-next-app`~~ — already done (Next.js 16.3.2, TypeScript, Tailwind v4, ESLint scaffolded and committed as the initial commit).
2. ~~Initialize shadcn/ui~~ — already done (`components.json`, `components/ui/button.tsx` present).
3. Add the color tokens table from `context/ui-context.md` (`paper`, `ink`, `ink-soft`, `line`, `brand`, `urgent`, `urgent-soft`, `safe`) to `app/globals.css` as CSS custom properties in `:root` plus corresponding `@theme` entries, following the existing shadcn variable pattern in that file. Note: `ui-context.md`'s teal token is named `brand`, not `accent` — shadcn already reserves `--accent` for its own component hover token.
4. Replace the default scaffold homepage with a minimal empty page (no chat UI — that's Spec 07).
5. Verify `npm run dev` starts cleanly with no console or TypeScript errors.
6. Push to GitHub, connect the repo to Vercel, deploy, confirm the live URL loads.

- No other dependencies beyond what `create-next-app` and `shadcn init` install by default.
